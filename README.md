# SCT_WD_2-
Smart Calculator Web Application

This repository contains a Smart Calculator Web Application developed using HTML, CSS, and JavaScript to practice frontend web development concepts including DOM manipulation, event handling, and dynamic UI interactions.

## Task Objective

To develop a fully functional and interactive calculator application capable of performing arithmetic operations with real-time calculations, keyboard support, error handling, and calculation history tracking.

## Tools Used

- HTML5  

- CSS3  

- JavaScript  

- Local Storage API  

- DOM Manipulation Techniques  

## ✨ Features Included

- Basic Arithmetic Operations  

- Keyboard Input Support  

- DOM Manipulation  

- Event Handling  

- Error Handling for Invalid Expressions  

- Recent Calculation History  

- Local Storage Integration  

- Responsive UI Design  

- Modern Glassmorphism Interface  

- Animated Premium Background Effects  

- Professional Dashboard Layout

- Built a fully functional smart calculator web application  

- Improved JavaScript logic and frontend development skills
